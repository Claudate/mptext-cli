mptext-cli 使用说明（Windows）
================================

【重要】不要直接双击 mptext.exe，会一闪而过。
请双击「启动 mptext.bat」，或在 CMD/PowerShell 里运行命令。

一、首次配置 Token
------------------
1. 打开 https://down.mptext.top 登录并复制 Auth Key
2. 在本目录打开 CMD，执行：
   mptext config set-token 你的密钥
3. 验证：
   mptext auth

二、常用命令
------------
搜索公众号：
  mptext search "公众号名称"

下载单篇：
  mptext download "https://mp.weixin.qq.com/s/xxxx" -o article.md

批量下载：
  mptext fetch --fakeid Mzxxxx --limit 10 --output-dir articles

三、配置文件位置
----------------
%APPDATA%\mptext\config.toml

四、仍无法运行？
----------------
1. 若提示缺少 VCRUNTIME，请安装 Microsoft Visual C++ 运行库
2. 在 CMD 中运行 mptext auth 查看完整错误信息
3. GitHub Issues: https://github.com/Claudate/mptext-cli/issues
